# Binohash-Level Overlay Primitives

Generated by `scripts/binohash_level_tools.py` with no node. Each primitive
turns one ossified seam into a specified overlay capability and checks a
cryptographic invariant. Digests are byte-reversed (`uint256::GetHex`).

## aggregatable_attestation

- Motif: `transcript_multiplicity`
- Mechanism: SIGHASH_SINGLE|ANYONECANPAY makes a signer's digest a function of only its own (input, output, index), so independently produced slots compose append-only without re-signing.
- Overlay use: threshold DLC/oracle attestation: any sufficient subset of position-ordered oracle slots composes into one settlement without a re-signing round

Invariants:
- PASS `digest_independent_of_other_slot_content`
- PASS `append_later_slot_preserves_earlier_digests`
- PASS `remove_earlier_slot_changes_digest`
- PASS `constant_one_collapse_detected_and_refused`

## state_bound_handle_rotation

- Motif: `identifier_bifurcation`
- Mechanism: a handle derived from the committed state hash can rotate across epochs while the state commitment is fixed and indexer-verifiable.
- Overlay use: rotating rendezvous / watchtower-alert / proof-anchor handles over a fixed channel or reserve state without re-anchoring the state

Invariants:
- PASS `legacy_txid_moves_digest_fixed`
- PASS `witness_anchor_fixed_across_rotation`
- PASS `all_handles_verify`

## binohash_grinding_bench

- Motif: `transcript_multiplicity`
- Mechanism: FindAndDelete makes the signed scriptCode depend on fed pushes; Binohash grinds a PoW nonce so the resulting digest is collision-resistant and Script-readable.
- Overlay use: trust-minimised transaction introspection for BitVM bridges without a soft fork; this bench picks (W1,W2) against a real cost line

Invariants:
- PASS `scriptcode_is_data_dependent`
- PASS `resistance_matches_w1_plus_w2`
